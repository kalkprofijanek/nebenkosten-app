# Mitwirken

Änderungen erfolgen ausschließlich über einen Task, einen eigenen Branch und einen eigenen Worktree. Pull Requests müssen klein bleiben, die Task-Akzeptanzkriterien erfüllen und alle relevanten Prüfungen bestehen.

Vor einem Pull Request:

```powershell
npm.cmd run ci
```

Die Legacy-Datei darf nicht geändert werden. Echte Daten sind auch in Tests, Screenshots, Logs und PR-Beschreibungen verboten.
